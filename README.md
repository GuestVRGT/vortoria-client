# vortoria-client

Full Vortoria client (hub + 3D play + Studio + clothing + PlayFab/Photon).

## Play (GitHub Pages, no local server)

1. **Settings → Pages** → Deploy from **main** / **/(root)**
2. Open: https://guestvrgt.github.io/vortoria-client/

## Controls
- Click game → pointer lock
- Mouse: **360°** look
- WASD move, Space jump
- Avatar faces movement direction
