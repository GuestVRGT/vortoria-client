# Finish installing the full client

Payload chunks are being pushed via API (size limits). To load the **complete** client in one step:

1. Download `vortoria-site.zip` from the Grok chat (full `index.html` + logic).
2. On https://github.com/GuestVRGT/vortoria-client → **Add file → Upload files**
3. Upload `index.html` (overwrite) so it is a single self-contained page (optional if all `p0.txt`…`p20.txt` are present).
4. **Settings → Pages** → main / root.

Play: https://guestvrgt.github.io/vortoria-client/
